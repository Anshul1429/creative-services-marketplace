# Creative Services Marketplace

A React, Vite, and Tailwind CSS application for discovering, hiring, and managing creative freelancers.

## Development

Install dependencies: npm ci
Start development server: npm run dev
Build for production: npm run build
Preview production build: npm run preview

## Project Structure

- src/ - Application source code, pages, components, and services
- public/ - Static assets
- index.html - HTML entry point
- package.json - Dependencies and npm scripts
- package-lock.json - Locked npm dependency versions
- vite.config.ts - Vite configuration
- tsconfig.json - TypeScript configuration

## Styling

The application uses Tailwind CSS v4 through its Vite plugin.

## Code Quality

Keep JSX syntax valid and run npm run build after changes.
